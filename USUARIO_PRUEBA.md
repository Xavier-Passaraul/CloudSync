# 🔐 Usuario de Prueba - CloudSync

## ⚠️ IMPORTANTE: PRIMERO DEBES REGISTRARTE

**CloudSync requiere que CREES UNA CUENTA NUEVA primero.**

### Opción 1: Usar tus propios datos (RECOMENDADO)
1. Haz clic en **"Regístrate"** en la pantalla de login
2. Ingresa tu nombre, email y contraseña
3. Haz clic en **"Crear cuenta"**
4. ¡Listo! Ya puedes usar CloudSync

### Opción 2: Usar datos de prueba sugeridos
**Nombre:** Demo User  
**Email:** tu-email@ejemplo.com  
**Contraseña:** (mínimo 6 caracteres)

> **Nota:** No puedes iniciar sesión con un usuario que no existe. Primero debes registrarte.

## ✨ Funcionalidades Implementadas

### 1. 💻 **Chat de Código con Syntax Highlighting**
- Editor Monaco integrado (mismo que VS Code)
- Soporte para 16 lenguajes de programación
- Modo código con syntax highlighting profesional
- Colores tipo VS Code (tema oscuro)
- Tipografía monoespaciada
- Scroll horizontal elegante
- Botón para alternar entre modo código y modo texto
- Copiar código al portapapeles con un clic

**Lenguajes soportados:**
- HTML, CSS, JavaScript, TypeScript
- React, Node.js, Python, PHP
- Java, C#, C++, SQL, JSON, Bash

### 2. 💬 **Chat Simple**
- Texto normal para notas rápidas
- Listas e ideas
- Sin formato de código
- Interfaz limpia y minimalista

### 3. 📁 **Sistema de Carpetas**
- Crear carpetas organizadas por tipo
- 4 tipos: PDF/Documentos, Imágenes, Videos, APK
- Iconos personalizables (Lucide React)
- Validación automática de archivos
- Contador de archivos por carpeta
- Grid moderno con animaciones

### 4. 📤 **Subida de Archivos**
- Drag & Drop en PC
- Selector de archivos en móvil
- Validación por tipo de carpeta
- Previews elegantes
- Botón flotante "+" para subir
- Descarga y eliminación

### 5. 🔄 **Sincronización Automática**
- Todo se sincroniza en tiempo real
- Funciona por WiFi, datos móviles o cualquier red
- NO requiere misma red local
- Indicador de sincronización en header
- Backend con Supabase

### 6. 🗑️ **Eliminar Datos**
- Borrar archivos individuales
- Borrar carpetas completas
- Borrar chats y mensajes
- Eliminar TODOS los datos de la cuenta
- Confirmación de seguridad
- Se elimina automáticamente en todos los dispositivos

### 7. 🍔 **Menú Hamburguesa Premium**

#### Mi Perfil
- Foto de perfil personalizable
- Nombre y email
- Estadísticas (carpetas, archivos, chats, mensajes)
- Guardar cambios

#### Integraciones
- Facebook (con icono oficial)
- Instagram (con gradiente oficial)
- GitHub (con icono oficial)
- Conectar/desconectar servicios
- Diseño moderno con tarjetas

#### Notificaciones
- Activar/desactivar notificaciones push
- Permisos del navegador
- Notificación de prueba al activar
- Icono dinámico (campana/campana tachada)

#### Modo Oscuro/Claro
- Switch entre temas
- Persistencia con localStorage
- Transiciones suaves

#### Eliminar Todos los Datos
- Modal de confirmación
- Elimina cuenta y todos los datos
- Cierra sesión automáticamente

### 8. 🔔 **Sistema de Notificaciones**
- Notificaciones push del navegador
- Solicitud de permisos
- Notificación de prueba
- Icono cambia según estado
- Preparado para notificaciones cuando se agrega archivo desde PC

### 9. 🎨 **Diseño Premium**
- Extremadamente fluido y rápido
- Animaciones suaves con Motion
- Colores modernos y neutros
- Modo oscuro profesional
- Bordes redondeados elegantes
- Sombras suaves
- Responsive total (PC y móvil)
- Inspirado en Notion, Telegram, VS Code

### 10. 🔐 **Autenticación Segura**
- Registro con nombre, email y contraseña
- Login persistente
- Gestión de sesiones con Supabase
- Logout seguro

## 🔧 Tecnologías Utilizadas

- **Frontend:** React + TypeScript
- **Styling:** Tailwind CSS v4
- **Animaciones:** Motion (Framer Motion)
- **Editor de Código:** Monaco Editor (VS Code)
- **Backend:** Supabase (Auth + Database + Functions)
- **Iconos:** Lucide React
- **Notificaciones:** Sonner + Web Notifications API
- **Drag & Drop:** react-dropzone

---

## ⚠️ Importante

- **Desplegar Edge Function** es OBLIGATORIO para que funcione
- Las notificaciones requieren HTTPS o localhost
- Crear cuenta nueva o usar credenciales de prueba
- Todo se sincroniza automáticamente en la nube
